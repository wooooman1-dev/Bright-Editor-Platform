# Releases

## Purpose

`current/` contains the latest working documentation.

`releases/` stores immutable release records.

Once a release is published, its documents are not edited.
Changes are introduced through the next release.

## Recommended Structure

releases/
├── README.md
├── v0.1.0/
├── v0.2.0/
├── v0.3.0/
└── v1.0.0/

Each release should contain:

- RELEASE.md
- CHANGELOG.md
- KNOWN_ISSUES.md
