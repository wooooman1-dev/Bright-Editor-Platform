# 06_GLOSSARY.md

## Glossary

Platform
: Bright Editor Platform.

Core
: Shared business logic used by every application.

App
: Platform-specific implementation (Tistory, YouTube, etc.).

Shared
: Reusable resources such as templates, assets, and settings.

AI Engine
: Generates structured content.

Editor Engine
: Improves generated content.

Quality Engine
: Reviews and scores output quality.

Prompt Engine
: Builds optimized prompts.

Image Strategy Engine
: Determines image purpose and placement.

Publishing Engine
: Handles publishing workflows.

Agent Ready
: Architecture that allows future separation into independent AI agents without major redesign.
