# Bright Studio Product Architecture

> Internal Project Name: **Bright Editor Platform**\
> User-facing Product: **Bright Studio**\
> Product Identity: **AI Content Operating System**

------------------------------------------------------------------------

# 1. Purpose

이 문서는 Bright Studio의 **제품 아키텍처**를 정의한다.

본 문서는 기술 아키텍처가 아니라 제품의 구조와 핵심 개념을 설명한다.

------------------------------------------------------------------------

# 2. Vision

Bright Studio는 콘텐츠를 작성하는 도구가 아니라 콘텐츠를 운영하는
플랫폼이다.

프로젝트 단위로 콘텐츠를 기획하고 생성하고 검토하고 발행하며 분석하는
전체 라이프사이클을 지원한다.

------------------------------------------------------------------------

# 3. Product Philosophy

-   Project First
-   Platform First
-   AI First
-   Quality First

사용자는 플랫폼을 사용하는 것이 아니라 **프로젝트를 운영**한다.

------------------------------------------------------------------------

# 4. Core Concepts

## Project

최상위 관리 단위

예시 - 밝은건강 - 부동산 - IT - 쇼핑

## Content

프로젝트에서 생성되는 모든 콘텐츠

-   글
-   이미지
-   영상
-   SEO
-   품질 결과

## Platform

-   Tistory
-   WordPress
-   YouTube
-   Naver Cafe
-   Instagram
-   Shopping

플랫폼은 콘텐츠를 배포하는 대상이다.

## Publishing

-   Draft
-   Schedule
-   Publish
-   History

## AI

-   Writer
-   SEO
-   Review
-   Image
-   Video
