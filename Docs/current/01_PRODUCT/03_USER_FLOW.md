# User Flow

## First-Run Flow

Workspace 없음

→ 작업 공간 만들기

→ 새 프로젝트 만들기

Project 생성 입력:

- 프로젝트 이름: 필수
- 브랜드 이름: 선택
- 프로젝트 설명: 선택

브랜드 이름을 입력하지 않으면 Project는 Workspace에 직접 생성된다. 브랜드 이름을 입력하면 현재 Workspace에서 동일한 Brand를 재사용하거나 새로 만든 뒤 Project를 연결한다. Brand 생성은 별도 선행 단계가 아니다.

→ Content 생성

## Daily Flow

Login → Continue Working → Open Project → Continue/Edit Content →
Quality Review → Publish → Review Results

## UX Principles

-   Never make users think.
-   Always remember unfinished work.
-   Resume from the exact point the user stopped.
-   Show the next recommended action.
