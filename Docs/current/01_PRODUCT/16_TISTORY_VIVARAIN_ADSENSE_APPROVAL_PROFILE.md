## 2. Site Identity

비바레인의 승인 준비 단계 사이트 정체성은 다음과 같다.

> 미술 초보 일반 독자가 서양미술의 화가와 작품을 단순 암기가 아니라 시대적 배경, 작품의 시각적 특징, 감상 포인트와 확인 가능한 자료를 통해 쉽게 이해하도록 돕는 미술 감상 가이드.

사이트가 미술관, 박물관, 경매사, 연구기관 또는 전문 자격 기관인 것처럼 표현하지 않는다.

---

## 3. Audience

초기 독자는 다음과 같다.

- 서양미술을 처음 공부하는 사람
- 유명 화가와 대표 작품의 차이를 이해하려는 사람
- 작품을 볼 때 무엇을 관찰해야 하는지 알고 싶은 사람
- 미술관 관람 전후에 기본 맥락을 확인하려는 사람
- 미술사 용어를 쉬운 설명으로 이해하려는 사람

전문 연구자 대상의 학술 논문처럼 쓰지 않는다. 반대로 사실을 생략한 감상문이나 감성 문구만으로 끝내지 않는다.

---

## 4. Preferred Content Scope

승인 준비 단계에서는 다음 주제를 우선한다.

- 한 작품을 중심으로 보는 구도, 색채, 시선, 상징과 감상 포인트
- 한 화가의 생애 중 작품 이해에 직접 필요한 배경
- 같은 주제나 장면을 다룬 작품 비교
- 미술 사조의 핵심 특징을 실제 작품과 연결한 설명
- 미술 초보가 자주 혼동하는 화가, 작품, 시대 또는 용어 비교
- 미술관에서 작품을 볼 때 사용할 수 있는 관찰 순서와 질문
- 공개 소장처, 공식 작품 페이지 및 신뢰 가능한 미술기관 자료를 확인하는 방법

---

## 5. Deferred or Excluded Content

다음 콘텐츠는 승인 준비 기본 범위에서 제외한다.

- 확인되지 않은 작품 가격, 투자 가치 또는 수익 전망
- 미술품 구매·경매 참여를 유도하는 추천
- 화가의 사생활을 자극적으로 소비하는 내용
- 출처 없는 명언과 일화
- 작품명, 제작연도, 소장처 또는 재료가 불확실한 상태의 단정
- 저작권이 확인되지 않은 고해상도 작품 이미지 재배포
- 동일한 화가 목록이나 대표작 목록을 제목만 바꿔 반복하는 글
- 작품 설명 없이 `유명 작품 10선`처럼 나열만 하는 글
- AI가 직접 작품을 보았거나 미술관을 방문한 것처럼 쓰는 체험형 문장
- 특정 화가 또는 작품의 우열을 객관적 사실처럼 단정하는 글

---

## 6. Source Priority

사실 확인은 다음 출처를 우선한다.

1. 작품을 소장한 미술관·박물관의 공식 작품 페이지
2. 작가 재단, 공식 아카이브 또는 catalogue raisonné 관련 공식 자료
3. 공공 미술기관과 대학 미술관 자료
4. 신뢰 가능한 백과사전과 학술 출판물
5. 전시 주최 기관의 공식 전시 자료

블로그, 커뮤니티, 출처 없는 이미지 설명, 자동 생성 요약은 핵심 사실의 최종 근거로 사용하지 않는다.

확인 대상:

- 화가 이름과 표기
- 작품명과 원어 표기
- 제작연도 또는 추정 시기
- 재료와 기법
- 크기
- 현재 소장처
- 작품의 역사적 배경
- 인용문과 일화의 출처

공식 자료가 서로 다르면 차이를 숨기지 않고 적용 범위와 표현을 조정한다.

---

## 7. Required Article Value

주제에 필요한 경우 다음 정보 요소를 포함한다.

- 작품 또는 화가를 이해해야 하는 이유
- 시대적·미술사적 배경
- 화면에서 실제로 관찰할 수 있는 특징
- 구도, 색채, 빛, 시선, 인물, 공간 또는 상징의 역할
- 초보 독자가 놓치기 쉬운 감상 포인트
- 흔한 오해 또는 과도한 해석과 구분할 점
- 관련 작품과 비교할 수 있는 기준
- 공식 소장처 또는 최종 확인 경로
- 주요 출처
- 최종 검토일

모든 글에 같은 소제목을 억지로 반복하지 않는다. 해당 작품과 검색 의도에 필요한 요소만 충분히 구성한다.

---

## 8. Originality and Duplicate Gate

다음 상태는 승인 준비 Quality Gate를 차단한다.

- 기존 비바레인 글과 핵심 질문, 목차 역할 및 결론이 실질적으로 동일함
- 화가 이름이나 작품명만 바꾸고 같은 구조를 반복함
- 작품 목록에 한두 문장 설명만 붙임
- 공식 페이지의 설명 순서와 표현을 그대로 따라감
- 작품의 실제 시각적 특징보다 일반적인 미사여구가 중심임
- 검색 의도와 무관한 생애 연표로 대부분을 채움
- 다른 글의 내부 링크를 채우기 위해 억지로 관련성을 만듦

새 글은 최소한 하나 이상의 명확한 독자 가치를 가져야 한다.

예:

- 작품을 보는 구체적인 관찰 순서
- 두 작품을 구분하는 비교 기준
- 초보자가 오해하는 표현의 교정
- 시대 배경이 화면 구성에 미친 영향
- 공식 작품 정보를 직접 확인하는 방법

---

## 9. Writing and Tone

- 한국어 존댓말을 사용한다.
- 미술 초보도 이해할 수 있는 표현을 사용한다.
- 어려운 용어는 작품 속 실제 요소와 연결해 설명한다.
- `천재`, `충격`, `소름`, `반드시 봐야 할` 같은 과장 표현을 반복하지 않는다.
- 해석을 하나의 확정된 정답처럼 제시하지 않는다.
- 확인된 사실과 감상 관점을 문장 안에서 구분한다.
- 의미 없는 감탄과 감성 문구로 정보 부족을 가리지 않는다.

---

## 10. Image Policy

작품 이미지는 장식이 아니라 설명을 지원해야 한다.

허용 방향:

- 공식 소장처가 제공하는 이용 조건을 확인한 작품 이미지
- 저작권이 만료된 작품의 신뢰 가능한 공개 이미지
- 작품 구도나 감상 순서를 설명하는 자체 제작 도식
- 화가와 사조의 관계를 설명하는 자체 제작 정보 카드

Bright Studio는 출처나 이용 조건이 확인되지 않은 작품 이미지를 자동 첨부하지 않는다.

이미지 Prompt는 원작을 허위로 복제하거나 특정 현존 작가의 스타일을 모방하도록 지시하지 않는다.

---

## 11. Internal Link Policy

내부 링크는 실제 공개된 비바레인 글만 사용한다.

우선순위:

1. 같은 화가의 직접 관련 작품
2. 같은 미술 사조 또는 시대
3. 동일한 감상 기준으로 비교 가능한 작품
4. 초보자를 위한 공통 감상 가이드

관련성이 확인되지 않으면 내부 링크 수를 억지로 채우지 않는다.

---

## 12. Approval Preparation Quality Checks

공통 Quality Review에 다음 프로필 검사를 추가한다.

- 비바레인 사이트 정체성과 주제 일치
- 작품·화가 핵심 사실의 출처 가능성
- 작품을 실제로 이해하게 하는 관찰 정보
- 단순 목록 또는 생애 연표 중심 여부
- 기존 비바레인 글과의 구조적 중복 위험
- 해석을 사실로 단정하는 표현
- 허위 체험 또는 출처 없는 명언·일화
- 작품 이미지 이용 조건 위험
- 공식 소장처 또는 확인 경로 제공 여부

정확성을 확인할 수 없는 핵심 사실이 남아 있으면 `승인 준비 기준 충족` 상태로 만들지 않는다.

## 13. Initial Project Defaults

비바레인 Project의 초기 승인 준비 기본값은 다음과 같다.

```text
Content Purpose: adsense_approval
Approval Profile: tistory_vivarain_art_v1
Platform: tistory
Review First: ON
Draft Only: ON
Public Publish: OFF
Scheduling: OFF
```

기본 Category는 실제 연결된 Tistory Category를 읽은 후 사용자가 선택한다. 존재하지 않는 Category를 만들거나 추정하지 않는다.

---

## 14. Completion Boundary

이 프로필 적용 완료는 실제 비바레인 Project에서 다음을 확인한 뒤에만 선언한다.

- Project에 프로필 저장
- 새 승인 준비 Content에 프로필 snapshot 저장
- Planning 추천이 미술 감상 범위를 벗어나지 않음
- Generation 결과에 허위 작품 정보와 출처 없는 명언이 없음
- Quality Review에서 프로필 미달 사유를 표시
- 화면 이동과 새로고침 후 목적·프로필 유지
- 기존 일반 콘텐츠 Workflow 회귀 없음

외부 AdSense 승인은 별도 결과이며 Bright Studio 내부 검증 완료와 동일하지 않다.
