# Competitive Advantage

## 1. Purpose

이 문서는 Bright Studio가 시장에서 선택받아야 하는 이유를 정의한다.

기능 목록이 아니라 대체하기 어려운 제품 가치에 집중한다.

---

## 2. Core Positioning

> Bright Studio는 AI Writer가 아니라 AI Content Operating System이다.

다른 도구가 콘텐츠를 생성하는 데 집중한다면, Bright Studio는 콘텐츠의 전체 운영을 지원한다.

---

## 3. Primary Differentiator

## Publish Ready Engine

Bright Studio는 초안을 제공하는 제품이 아니다.

```text
Generate
→ Review
→ Improve
→ Validate
→ Publish Ready
```

사용자는 AI가 만든 낮은 품질의 결과를 반복해서 고치는 사람이 아니다.

사용자는 최종 결과를 검토하고 승인한다.

---

## 4. Strategic Differentiators

### 4.1 Content Memory

Bright Studio는 사용자의 프로젝트와 콘텐츠를 기억한다.

- 기존 콘텐츠와의 중복 탐지
- 검색 의도 충돌 탐지
- 키워드 Cannibalization 방지
- 내부 링크 추천
- 콘텐츠 클러스터 제안
- 과거 콘텐츠 재사용
- 브랜드 스타일 일관성 유지

### 4.2 Content Business Brain

Bright Studio는 무엇을 쓸지 결정하는 데 도움을 준다.

- 다음 콘텐츠 추천
- 기존 콘텐츠 연결 가능성
- 성과 개선 가능성
- 플랫폼별 우선순위
- 수익성과 성장 가능성
- 업데이트가 필요한 콘텐츠 탐지

### 4.3 One Click Repurpose

하나의 ContentDocument를 여러 플랫폼에 맞게 변환한다.

```text
YouTube
→ Blog
→ Tistory
→ WordPress
→ Naver Cafe
→ Shopping
```

단순 복사가 아니라 플랫폼 목적과 형식에 맞게 재구성한다.

### 4.4 Continuous Improvement

발행으로 끝나지 않는다.

- 성과 확인
- 제목 개선 제안
- 오래된 정보 업데이트
- 내부 링크 보강
- 콘텐츠 재활용 제안
- 플랫폼 확장 추천

---

## 5. Why Not Just ChatGPT?

ChatGPT는 강력한 범용 AI다.

Bright Studio는 범용 대화를 경쟁 영역으로 삼지 않는다.

Bright Studio가 제공해야 하는 추가 가치는 다음과 같다.

- 프로젝트 전체 맥락
- 콘텐츠 이력
- 품질 기준
- 플랫폼별 Output
- 반복 가능한 Workflow
- 콘텐츠 성과와 개선
- 쉬운 사용자 경험
- 발행 자동화

---

## 6. Feature Score

새 기능은 아래 항목으로 평가한다.

| 항목 | 질문 |
|---|---|
| 차별성 | 범용 AI만으로 동일하게 하기 어려운가? |
| WOW | 처음 본 사용자가 즉시 가치를 느끼는가? |
| 시간 절약 | 콘텐츠 제작 시간을 줄이는가? |
| 성과 | 품질, 유입, 전환 또는 수익에 기여하는가? |
| 단순함 | 초보자도 쉽게 사용할 수 있는가? |
| 재사용성 | 여러 플랫폼과 도메인에 확장 가능한가? |

점수가 낮은 기능은 구현보다 Backlog에 둔다.

---

## 7. Anti Goals

Bright Studio는 다음 제품을 복제하지 않는다.

- 범용 Chatbot
- Word Processor
- Notion Clone
- Canva Clone
- Tistory Editor Clone
- 복잡한 SEO Dashboard

필요한 기능은 가져오되 Bright Studio의 핵심 흐름에 통합한다.

---

## 8. Competitive Promise

> Bright Studio는 사용자가 더 많이 일하도록 만드는 AI가 아니라, 사용자의 콘텐츠 사업을 대신 운영하는 AI Partner가 된다.
