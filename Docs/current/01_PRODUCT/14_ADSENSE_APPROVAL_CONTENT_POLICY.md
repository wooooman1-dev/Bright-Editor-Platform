# AdSense Approval Content Policy

Version: 1.0

Status: Accepted

Applies to: Bright Studio WordPress 생활경제 Project의 AdSense 승인 준비 단계

Last updated: 2026-07-30

---

## 1. Purpose

이 문서는 Bright Studio가 WordPress 생활경제 사이트의 AdSense 승인 준비용 콘텐츠를 기획, 생성, 검토, 임시저장할 때 따라야 하는 제품 정책을 정의한다.

이 정책은 글 개수나 글자 수를 기계적으로 채우는 전략이 아니라 다음을 목표로 한다.

- 사이트의 명확한 주제와 목적 유지
- 독자에게 실제 도움이 되는 고유한 정보 제공
- 공식 자료에 근거한 정확성과 최신성 확보
- 빈 페이지, 얇은 분류 페이지, 반복 원고 방지
- AdSense 신청 전 사이트 완성도와 신뢰성 확보

Google의 공식 정책과 안내가 변경될 수 있으므로 신청 직전에는 최신 공식 문서를 다시 확인한다.

## 2. Site Identity

초기 사이트 분야는 `생활경제`다.

사이트 목적은 다음과 같다.

> 복잡한 정부지원, 세금, 주거, 생활금융 기초 제도를 일반 독자가 이해하고 공식 확인처에서 스스로 확인할 수 있도록 쉽게 설명한다.

초기 독자는 다음과 같다.

- 정부지원 제도의 대상과 신청 방법을 찾는 사람
- 세금과 신고 절차의 기초를 이해하려는 사람
- 주거 관련 제도와 비용 구조를 확인하려는 사람
- 금융상품 추천이 아니라 생활금융의 기본 원리와 공공 정보를 찾는 사람

사이트가 정부기관, 금융기관 또는 공식 신청기관인 것처럼 표현하지 않는다.

## 3. Initial Category Policy

AdSense 승인 준비 단계의 WordPress Category는 `생활경제` 하나만 사용한다.

```text
생활경제
├── 정부지원
├── 세금 기초
├── 주거 제도
└── 생활금융 기초
```

위 하위 항목은 초기에는 별도 Category가 아니라 콘텐츠 주제다.

규칙:

- 빈 Category를 만들지 않는다.
- 초기에는 Tag를 사용하지 않는다.
- `미분류` Category에 원고를 남기지 않는다.
- 승인 전에는 정부지원, 세금, 주거, 생활금융을 각각 별도 Category로 분리하지 않는다.
- 승인 후 콘텐츠와 실제 이용 데이터가 충분한 주제만 별도 Category로 분리한다.
- Category 수나 게시물 수를 승인 통과 기준으로 사용하지 않는다.

## 4. Approval-stage Content Scope

### 4.1 Preferred topics

승인 준비 단계에서는 공식 자료로 확인 가능하고 일반 독자의 문제 해결에 직접 도움이 되는 정보형 원고를 우선한다.

- 정부지원 제도의 의미, 대상, 신청 절차
- 세금 신고와 납부의 기초 절차
- 주거 지원, 임대, 계약과 관련된 공공 정보
- 금융감독원, 예금보험공사 등 공식 기관이 제공하는 생활금융 기초정보
- 신청 서류, 확인 방법, 제외 조건, 주의사항
- 제도가 변경됐는지 공식적으로 확인하는 방법

### 4.2 Deferred topics

다음 주제는 승인 준비 단계의 기본 범위에서 제외한다.

- 개별 주식, 가상자산, 파생상품 추천
- 고수익 투자 전략
- 대출 승인 가능성 예측 또는 보장
- 카드, 보험, 대출상품의 가입 유도형 비교
- 특정 금융상품을 사실상 광고하는 원고
- 확정 수익, 절세 보장, 지원금 수령 보장 표현
- 실시간 공식 자료 없이 작성하는 신청 기간, 금액, 금리, 세율

승인 후에도 위 주제를 다루려면 별도 정책 승인과 더 강한 정확성 Gate가 필요하다.

## 5. Source and Accuracy Policy

생활경제 원고는 정확성과 최신성이 중요한 정보로 취급한다.

우선 출처:

- 중앙정부와 지방자치단체
- 국세청과 법령정보
- 금융위원회와 금융감독원
- 한국주택금융공사, 주택도시보증공사 등 공공기관
- 예금보험공사와 공적 안내 기관
- 공식 사업 공고와 공식 신청 페이지
- 금융회사 공식 상품설명서가 필요한 경우 해당 공식 문서

필수 규칙:

- 신청 기간, 대상, 금액, 소득 기준, 금리, 세율은 공식 출처로 확인한다.
- 변경 가능한 정보에는 `정보 기준일`을 표시한다.
- 원고에는 `최종 검토일`을 기록한다.
- 주요 공식 출처와 공식 확인 경로를 제공한다.
- 확인된 사실과 해석 또는 일반적인 설명을 구분한다.
- 출처에서 확인되지 않은 내용을 사실처럼 단정하지 않는다.
- 공식 자료가 서로 다르면 최신 공고와 적용 범위를 확인하고 불일치를 숨기지 않는다.
- 최신성을 확인하지 못한 원고는 승인 완료 상태로 만들지 않는다.

## 6. Required Article Information

각 원고는 검색 의도와 독자 문제에 맞춰 필요한 정보만 충분히 제공한다.

주제에 해당하는 경우 다음 요소를 포함한다.

- 제도 또는 용어의 의미
- 대상과 적용 조건
- 본인이 대상인지 확인하는 방법
- 신청 또는 처리 기간
- 준비 서류
- 단계별 신청 또는 신고 절차
- 제외되는 경우
- 비용, 세금, 금리 또는 지원액의 계산 기준
- 자주 하는 실수
- 주의사항과 변경 가능성
- 공식 문의처 또는 최종 확인처
- 정보 기준일과 최종 검토일

모든 원고에 동일한 항목을 억지로 채우지 않는다. 해당 주제에 필요한 정보 요소를 판단한다.

## 7. Content Quality Gate

승인용 원고도 Bright Studio의 기존 품질 원칙을 따른다.

통과 기준:

- 검색 의도를 충족한다.
- 독자의 실제 문제를 해결한다.
- 필수 정보 요소와 섹션이 완결되어 있다.
- 정보 밀도가 충분하다.
- 반복과 불필요한 확장이 없다.
- 공식 출처와 기준일이 확인된다.
- 제목과 본문이 과장되지 않는다.
- 모바일에서 읽기 쉽다.
- 관련성이 있는 공개 콘텐츠가 존재할 때만 내부 링크를 제공한다.
- 광고가 없어도 독립적인 정보 가치가 있다.

사용하지 않는 기준:

- 목표 글자 수
- 최소 문단 수
- 최소 Category 수
- 최소 게시물 수를 공식 승인 조건처럼 사용하는 것

AI 호출 정책:

```text
AI Generation 1회
→ Rule and Editorial Quality Review 1회
```

AdSense 승인 정책은 기존 Generation과 Quality Review에 포함한다. 별도의 불필요한 AI 호출을 추가하지 않는다.

### 7.1 WordPress People-First Writing and Review Criteria

이 프로필은 `15_ADSENSE_APPROVAL_MODE.md`의 People-First Value and Trust Principle을 따른다. 생활경제 승인 준비 원고는 검색 시스템이나 심사 시스템을 공략하는 문서가 아니라 실제 독자의 질문과 문제를 완결적으로 해결하는 문서여야 한다.

작성 기준:

- 독자의 구체적인 질문이나 문제를 먼저 정의하고 서론에서 핵심 답변을 불필요하게 미루지 않는다.
- 검색 의도에 필요한 판단 기준, 조건, 예외, 실행 방법과 다음 행동을 빠짐없이 제공한다.
- 다른 문서를 단순 요약·재작성하지 않는다. 주제에 적합한 고유한 설명, 비교, 사례, 계산, 체크리스트, 주의점 또는 선택 기준을 제공한다.
- 사실과 편집 해석을 구분하고 변동 가능한 정보에는 기준일 또는 확인 시점을 표시한다.
- 중요한 주장은 공식 또는 신뢰할 수 있는 출처로 뒷받침한다.
- 확인하지 않은 수치, 경험담, 성공 사례 또는 전문가 자격을 생성하지 않는다.
- 불확실하거나 조건에 따라 달라지는 내용은 적용 범위와 한계를 명시한다.
- 제목과 소제목은 실제 내용을 정확히 설명한다.
- 키워드 반복, 문장 부풀리기, 의미 없는 서론과 결론을 금지하고 정보 밀도를 유지하면서 중복과 불필요한 장문을 제거한다.
- 관련성이 검증된 공개 글만 내부 링크로 사용한다.
- 승인 보장, 수익 보장, 반드시 통과 또는 100% 승인이라는 표현을 사용하지 않는다.
- 생활경제 사이트의 주제와 대상 독자에 맞는 일관성을 유지한다.

기존 단일 Quality Review는 별도 필드나 AdSense 승인 가능성 점수를 만들지 않고 기존 평가 항목의 설명과 판정 기준에서 다음 관점을 함께 평가한다.

```text
Reader Value
Original Contribution
Factual Reliability
Completeness
Transparency
Readability
Search Intent Satisfaction
Policy Safety
```

글자 수는 위 관점의 통과 기준이 아니다. Search Console, Analytics, 검색엔진 차단, 실제 색인 및 sitemap 제출 상태는 이 원고 검토가 아니라 WordPress Site Approval Readiness에서 별도로 다룬다.

## 8. Prohibited Content Practices

다음 원고는 승인 준비용으로 사용할 수 없다.

- 다른 사이트나 공식 문서를 문장만 바꿔 재작성한 원고
- 제목과 키워드만 바꾼 반복 원고
- 검색 유입만을 위한 대량 유사 원고
- 출처 없는 지원금, 세율, 금리, 신청 기간
- 존재하지 않는 공식 기관, 신청처 또는 URL
- `무조건`, `100%`, `반드시 승인`, `확실한 절세`, `누구나 받는다` 같은 보장 표현
- 독자의 불안을 과도하게 자극하는 클릭베이트
- 실제 근거 없이 긴급성이나 마감 임박을 강조하는 표현
- 공식 사이트로 오인하게 하는 디자인과 문구
- 저작권이 확인되지 않은 이미지와 자료
- 원고의 실제 내용보다 광고 또는 제휴 유도가 중심인 페이지

## 9. Author and Editorial Transparency

게시글에는 다음 정보를 표시할 수 있어야 한다.

- 작성 주체: 예: `밝은생활경제 편집팀`
- 최초 작성일
- 최종 검토일
- 정보 기준일
- 주요 공식 출처

사이트 소개 페이지에는 다음 편집 원칙을 공개한다.

- 공식 자료 우선
- AI는 초안과 편집 보조에 사용될 수 있음
- 최종 원고는 편집 및 품질 검토를 거침
- 과장과 보장 표현을 사용하지 않음
- 변경된 제도는 확인 후 수정
- 오류 제보와 문의 경로 제공

전문 자격을 보유하지 않은 경우 전문가인 것처럼 표현하지 않는다.

## 10. Required Site Pages and Navigation

AdSense 신청 전 다음 공개 페이지를 준비한다.

```text
홈
생활경제
사이트 소개
문의하기
개인정보처리방침
경제정보 이용 안내
```

경제정보 이용 안내에는 다음을 포함한다.

- 본 사이트는 정부기관이나 금융기관이 아님
- 정보는 작성 또는 검토 시점 기준임
- 제도와 조건은 변경될 수 있음
- 신청, 세금, 금융 결정 전 공식 기관에서 최종 확인해야 함
- 오류 제보 및 수정 요청 방법

규칙:

- 빈 메뉴를 만들지 않는다.
- 공사 중 페이지를 공개 메뉴에 연결하지 않는다.
- 깨진 링크를 허용하지 않는다.
- 중요한 페이지는 모바일에서도 쉽게 접근할 수 있어야 한다.

## 11. Privacy and Advertising Readiness

개인정보처리방침에는 실제 사이트 기능에 맞는 다음 내용을 포함한다.

- 사이트가 수집하는 정보와 이용 목적
- 문의 과정에서 수집될 수 있는 정보
- 쿠키와 유사 기술 사용 가능성
- Google 등 제3자 광고 공급자가 쿠키 또는 식별 기술을 사용할 수 있다는 안내
- 개인 맞춤 광고와 선택 해제 관련 공식 안내 경로
- 개인정보 관련 문의 방법

초기 승인 단계에서는 다음 기능을 넣지 않는다.

- 신용점수, 부채, 소득, 대출 상태를 입력받는 진단 폼
- 불필요한 회원가입
- 민감한 금융정보 수집
- 개인정보 수집 목적이 불명확한 이벤트 또는 상담 폼

실제 기능과 다른 개인정보처리방침을 복사해 사용하지 않는다.

## 12. WordPress Technical Readiness Gate

AdSense 신청 전 다음을 실제 사이트에서 확인한다.

- 개인 도메인 연결
- HTTPS 정상
- 비밀번호, 점검 모드 또는 접근 제한 없음
- 검색엔진 공개 설정
- 주요 페이지에 의도하지 않은 `noindex` 없음
- XML Sitemap 생성 및 접근 가능
- Google Search Console 연결
- 주요 콘텐츠와 필수 페이지의 크롤링 가능 여부
- 모바일 레이아웃 정상
- 대표이미지와 본문 이미지 정상
- 내부 링크와 메뉴 정상
- 빈 Category와 Tag archive 없음
- 개인정보처리방침과 문의 페이지 접근 가능
- WordPress REST API와 Bright Studio Draft 연결 정상

기술 Gate는 실제 화면, 실제 응답, 실제 Search Console 상태를 근거로 판단한다.

## 13. WordPress Publishing Policy

승인 준비 단계의 WordPress 실행 정책은 다음과 같다.

- Review First: ON
- Draft Only: ON
- Public Publish: OFF
- Scheduling: OFF
- Existing Post Update: OFF
- Post Delete: OFF
- Plugin Modification: OFF
- Theme Modification through Publishing Adapter: OFF

Bright Studio의 목표 흐름:

```text
Planning
→ Generation
→ Quality Review
→ WordPress Preview
→ User Confirmation
→ WordPress Draft Save
→ Draft Re-read
→ Verify Title, Body, Category, Featured Image and Draft Status
```

Theme 디자인은 WordPress Publishing Adapter와 분리된 Bright Theme 개발 흐름에서 관리한다.

## 14. AdSense Application Readiness Gate

게시물 개수만으로 신청 가능 여부를 결정하지 않는다.

다음 조건을 모두 검토한다.

- 생활경제라는 명확한 사이트 목적 유지
- 승인용 콘텐츠가 독자 문제를 충분히 해결함
- 공식 출처, 기준일, 검토일 확인
- 반복 원고와 얇은 원고 없음
- 소개, 문의, 개인정보처리방침, 경제정보 이용 안내 완성
- 메뉴와 내부 링크 정상
- 빈 페이지와 깨진 링크 없음
- 모바일과 HTTPS 정상
- 검색엔진과 AdSense가 사이트에 접근 가능
- 정책 위반 가능성이 있는 콘텐츠 없음

Gate 결과는 다음 중 하나다.

- `not_ready`: 필수 콘텐츠 또는 사이트 요소 미완성
- `review_required`: 사실, 출처, 정책 또는 기술 상태 재확인 필요
- `ready_to_apply`: 내부 Gate 통과, 단 Google의 승인 결과를 보장하지 않음

Bright Studio는 `ready_to_apply`를 AdSense 승인 보장으로 표현하지 않는다.

## 15. Post-approval Transition

AdSense 승인 이후에도 이 문서의 정확성, 출처, 금지 표현, 개인정보 보호 원칙은 유지한다.

승인 후 별도 검토를 거쳐 확장할 수 있는 항목:

- 콘텐츠가 충분한 주제의 Category 분리
- 실제 이용 데이터를 근거로 한 내부 링크 강화
- 광고 위치 최적화
- 소상공인 정책 콘텐츠 확장
- 제한된 금융상품 비교 콘텐츠
- 예약 발행

확장 시 다음을 금지한다.

- 승인 직후 사이트 주제를 무분별하게 변경
- 품질 Gate 없이 대량 콘텐츠 생성
- 빈 Category와 Tag 대량 생성
- 광고를 콘텐츠보다 우선하는 레이아웃
