## AI Development Rules

- Discuss architecture before implementation.
- Never write code before user approval.
- Build incrementally.
- Protect existing functionality.
- Keep modules independent.
- Reuse Core whenever possible.
- Optimize AI calls.
- Read project documentation before coding.
- Follow Platform First Architecture.
- Think long-term before implementing.

Development Order

Mission
→ Vision
→ Product Principles
→ PRD
→ Architecture
→ Development
→ Testing
→ Release
