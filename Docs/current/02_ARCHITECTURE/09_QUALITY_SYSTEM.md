# 09_QUALITY_SYSTEM

## Purpose

Define measurable quality standards for all generated content.

## Workflow

``` text
Generation
    ↓
Quality Review
    ↓
Rule Validation
    ↓
Approved
```

## Quality Categories

  Category           Target
  ------------------ --------
  SEO                ≥95
  Readability        ≥95
  Search Intent      ≥95
  HTML Quality       ≥95
  Image Strategy     ≥95
  Internal Linking   ≥95
  Overall            ≥95

## Validation Layers

### AI Review

-   Logical flow
-   Missing sections
-   Tone
-   User value

### Rule Validation

-   HTML structure
-   Metadata
-   ALT text
-   Heading hierarchy
-   Internal links
-   Required blocks

## Fail Policy

If the quality target is not achieved:

1.  Improve automatically where rules allow.
2.  Request one additional AI review only when necessary.

## Long-term Vision

Support automated quality scoring across all supported publishing
platforms.
