# AI Reasoning Framework

## Objective

Every AI task must follow the same reasoning process.

## Standard Reasoning Flow

1.  Understand Project
2.  Understand User Intent
3.  Analyze Target Reader
4.  Build Content Plan
5.  Generate Draft
6.  Improve Structure
7.  Apply SEO
8.  Plan Images
9.  Suggest Internal Links
10. Run Quality Review
11. Generate Final Output

## Rules

-   Never skip quality review.
-   Never publish low-quality content.
-   Prefer improving over regenerating.
-   Follow Project DNA before generating.
