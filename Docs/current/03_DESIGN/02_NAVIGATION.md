# Bright Studio Navigation Specification

## Philosophy
Navigation must expose the product structure, not the implementation.

## Global Navigation
- Home
- Projects
- Library
- Templates
- Publish
- Analytics
- Settings

## Rules
1. Home has NO persistent left sidebar.
2. Global navigation lives in the top header on Home.
3. Workspace screens may display a contextual sidebar.
4. Navigation names must remain stable across editions.
