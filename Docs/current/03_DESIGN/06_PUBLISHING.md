# Publishing

Goals - One-click publishing - Safe publishing - Quality check before
publish - Multi-platform support

Tistory Publishing Preparation shows a real category dropdown only for an enabled, connected, verified Workspace account. It includes nested-category indentation, explicit `카테고리 없음`, refresh, loading, empty, failure, and `재연결 필요` states. Preview and Draft Save use the same persisted account/category preparation.

User-facing results distinguish local save, external draft queued, partially verified external draft, and externally saved-and-verified draft. Public publishing remains unavailable.
