# Bright Editor Platform

# 05_PROJECT_GUIDE.md

## Overview

Bright Editor Platform is an AI-powered content editing platform.

The first application is Bright Editor – Tistory Edition.

Future editions include:

- YouTube
- Naver Cafe
- Blog
- Shopping

## Objectives

- Professional-quality content
- AI-assisted editing
- Intelligent publishing
- Shared AI Core
- Cross-platform architecture
